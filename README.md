# 🌅 Horizon 1.0 Website

Official website for **Horizon 1.0: New Dawn to Build Upon** - a technical and cultural mini-fest organized by IEEE VGEC Student Branch.

## 📋 About

This website serves as the central platform for Horizon 1.0, featuring event information, registration, schedule, and all details about the fest happening on **February 20, 2026** at VGEC Campus.

## 🌐 Website Features

- **Event Information** - Complete details about activities and attractions
- **Registration Portal** - Online registration for participants
- **Schedule & Timeline** - Event itinerary and timings
- **Contact Section** - Quick access to organizers
- **Responsive Design** - Optimized for all devices

## 🛠️ Technology Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
- **Framework:** None - Pure HTML/CSS/JS
- **Hosting:** Netlify

## 🚀 Getting Started

### Installation

```bash
# Clone the repository
git clone [repository-url]

# Navigate to project directory
cd horizon-website

# Install dependencies (if using any build tools)
npm install

# Start local development server
npm start
```

Or simply open `public/index.html` in your browser for quick testing.

### Deployment

The site is automatically deployed to Netlify on push to the main branch.
